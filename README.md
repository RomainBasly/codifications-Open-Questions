## 📥 Installation

1. **Cloner le dépôt** :
   ```bash
   git clone URL
   cd codification-Open-Questions
   ```

2. **Créer un environnement virtuel dédié** : 
    python3 -m venv venv
    source venv/bin/activate

3. **Installer les dépendances**
    pip install -r requirements.txt
